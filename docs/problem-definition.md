# 내일의집 통합 물류 네트워크 문제정의

## 원본과 범위

원본은 저장소 루트의 `NET_CASE_네트워크설계_내일의집.pdf`(11쪽)와 `GLR_CASE_내일의집_수요정보.xlsx`이다. 시작 시 Git은 clean, 기존 커밋은 `c8b0790`이며 두 원본은 수정하지 않는다. 본 도구는 교육용 사례를 로컬에서 분석한다. 원본의 배포·영리 이용 제한을 준수한다.

비즈니스 문제는 수도권 소형가구 당일배송을 위한 일별 물류비 최소화이다. 공급 흐름은 이천 CDC → 경기도 DC → 고정 수요지역이며, 배송 회차는 DC → 단일 수요지역 → DC이다. 방문 순서를 결정하는 VRP가 아니다.

## 데이터 구조 및 독립 검증

Excel `Sheet1!A1:G67`은 헤더와 66지역이다. 열은 `지역, 인구, 위도, 경도, 대형, 소형, 프리미엄_소형`. 일별 합계는 대형 2,108개, 소형 19,070개, 프리미엄 5,925개, 전체 **27,103개 / 7,107 CBM**이다. 인구 합계 26,120,000명. 위경도 범위는 36.9921–38.0966 / 126.4878–127.6371. 수식, 누락, 음수, 지역 ID·좌표 중복은 발견되지 않았다. 원본 숫자는 변환 후에도 일치 검증한다.

## 의사결정

1. 후보 생성: 경기 31지역에서 재현 가능한 입지 휴리스틱으로 기본 10개 생성; 지도에서 사용자가 수정 가능.
2. 개설: 후보 중 실제 운영 DC의 이진 결정.
3. 배정: 기간별 각 지역의 담당 DC 하나(전량 미충족 시 무배정 허용).
4. 상품별 출고 및 미충족량: 개수 단위 정수 결정.
5. 차량: 각 DC–지역–일반/프리미엄 운송군의 차종별 정수 회차 결정.

다기간은 개설만 모든 기간에 공유하고 배정·물량·회차는 기간별 결정한다. 후보 좌표를 바꾸면 거리행렬을 다시 만들고 이산입지 최적화를 재실행한다. 연속 좌표의 전역 최적해를 보장하는 모델은 아니다.

## 목적함수, 제약 및 결과

목적함수는 개설비+처리비+공급비+일반 운송비+프리미엄 운송비+미충족 패널티 합계이다. 상품 구매원가·매출은 공급비와 구분하며 비용 최소화의 기본 목적에서 제외한다. 물량 보존, 단일 DC 배정, 개설 연계, 분리운송, 차량 적재, 프리미엄 거리, 선택적 DC 용량을 적용한다. 추가 템플릿으로 최소/최대 DC 수, 강제/금지 개설, 지역–DC 허용/금지, 일반 최대거리, 차량 회차 상한, 충족률, 예산을 지원한다. 템플릿으로 표현되지 않는 정책은 7개 선형 집계(개설 수·배정·출고 물량·출고 부피·미충족·회차·운행거리)의 계수 결합으로 사용자 정의 제약식을 직접 작성한다.

출력은 비용 분해, 개설 위치, 상품별 배정·미충족, 차종/운송군별 회차·적재율, 개설 DC 수·처리량, 왕복 운행거리, 물량가중 평균 편도 배송거리, 최대 편도거리, 충족률, 해 상태·계산시간·MIP gap이다. 비용에는 편도, 운행거리 KPI에는 왕복을 사용한다. 다기간에는 연도별 일평균과 365일 누적비용을 구분한다.

추가 가정은 [assumptions.md](assumptions.md), 후속 수식·기술 결정은 별도 문서에 기록한다.
