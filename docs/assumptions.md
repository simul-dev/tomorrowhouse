# 가정·해석과 영향

PDF 요구사항과 다음 연구자 가정을 구분한다. 사용자가 시나리오에서 변경 가능한 값은 설정으로 노출한다.

|---|---|---|

| A02 | 수요지역 하나에 담당 DC 하나; 상품별로 다른 DC를 쓰지 않음 | 분할배정보다 보수적인 서비스 구조. 프리미엄 미충족이어도 일반 배송 가능 |

거리 임계값 부근은 수치 허용오차 1e-6km, 물량·비용 검증은 규모에 맞는 수치 허용오차를 사용한다. Solver 시간 제한 종료 시 실행 가능한 incumbent가 있는 경우에만 결과를 반환하며, 최적성 미증명 상태와 gap을 표시한다. 미실행·미검증 항목을 완료로 표시하지 않는다.
