# 수리모형: 다품목·다차종 직배송 시설입지 MILP

## 집합과 입력

후보 DC i∈I, 고정 수요지역 j∈J, 상품 p∈{large,small,premium}, 차량 k∈K, 기간 t∈T. 상품 부피 v=(1,0.2,0.2) CBM/개. D_jpt는 성장률 적용 후 정수 수요, d_ij는 재계산된 편도 Haversine km. F_i는 일별 개설비, h_i는 개당 처리비, b는 개당 CDC 공급비, π는 개당 미충족 패널티. 차량 용량 Q_k, 회당 고정비 f_k, km당 c_k. 기간 가중치 w_t는 운영일수(초기 구현은 할인 없음), 비용 시나리오 가중치는 α(개설), β(운송)이다.

운송군 G는 기본 {normal,premium}이고 normal={large,small}, premium={premium}. 가상 혼재 비교에서는 G={mixed}로 통합하되 프리미엄 상품의 거리제한은 유지한다.

## 변수

- y_i∈{0,1}: 개설. 다기간에 공유한다.
- a_ijt∈{0,1}: 담당 DC. 지역·기간별 최대 한 곳.
- q_ijpt∈Z₊: 상품별 충족 출고 개수.
- u_jpt∈Z₊: 상품별 미충족 개수.
- n_ijgkt∈Z₊: 구간·운송군·차종별 왕복 회차 수.

## 목적함수

min Σ_t w_t [Σ_i αF_i y_i + Σ_ijp (h_i+b)q_ijpt + Σ_ijgk β(f_k+c_k d_ij)n_ijgkt + Σ_jp πu_jpt]

개설비는 한 번의 투자비가 아니라 일별 임대료이므로 모든 운영일에 부과한다. 화폐 스케일은 Solver 내부에서 원→백만원으로 조정할 수 있지만 출력은 원이다. 매출·구매원가는 본 물류비 목적에 포함하지 않는다.

## 기본 제약

1. 수요보존: Σ_i q_ijpt + u_jpt = D_jpt.
2. 담당거점: Σ_i a_ijt ≤ 1; a_ijt ≤ y_i; q_ijpt ≤ D_jpt a_ijt.
3. 불필요한 배정 제거: a_ijt ≤ Σ_p q_ijpt. 수요 미충족만 있는 지역은 담당 없음.
4. 운송군별 용량: Σ_{p∈g} v_p q_ijpt ≤ Σ_k Q_k n_ijgkt.
5. 회차 연계: n_ijgkt ≤ M_jgt a_ijt, M은 해당 수요 CBM/최소 활성 차량용량의 올림으로 유효한 상한. 필요량보다 큰 단일 회차도 허용한다.
6. 프리미엄 서비스: 활성 제한 R_p에 대해 d_ij>R_p이면 q_ij,premium,t=0. 일반 상품에는 자동 적용하지 않는다.
7. 비활성 후보/차량: y_i=0 또는 해당 n=0.
8. 미충족 비허용 시 u=0. 허용 시 패널티와 충족률 제약을 적용한다.

## 선택적 제약 템플릿

- 개설 수 L≤Σ_i y_i≤U.
- DC 처리용량 Σ_jp v_p q_ijpt≤C_i y_i (Base에서는 비활성).
- 전체 상품 최대 배송거리 또는 지역별 거리: 제한 초과 상품 출고 q=0.
- 특정 거점 강제/금지 y_i=1/0.
- 특정 지역에 허용 DC 목록(allow_assignment 행들의 합집합) 또는 금지 DC: 해당 a 상한 0.
- 차종 일별 회차 상한 Σ_ijg n_ijgkt≤N_kt.
- 전체 상품 개수 기준 충족률 Σ_ijp q_ijpt≥ρΣ_jp D_jpt (매 기간 적용).
- 예산: 각 기간의 일별 총비용 ≤B. 다기간 누적 예산으로 오해하지 않도록 표시한다.
- 사용자 정의 선형 제약: Σ_m γ_m·A_m(t) {≤,≥,=} b. A_m은 아래 7개 선형 집계 중 하나이고 γ_m은 실수 계수이다.

| 집계 A_m | 모형 표현 | 지정 가능한 범위 |
|---|---|---|
| 개설 DC 수 | Σ_i y_i | 특정 DC |
| 배정 지역 수 | Σ_ij a_ijt | DC, 지역 |
| 출고 물량 | Σ_ijp q_ijpt | DC, 지역, 상품 |
| 출고 부피 | Σ_ijp v_p·q_ijpt | DC, 지역, 상품 |
| 미충족 물량 | Σ_jp u_jpt | 지역, 상품 |
| 차량 회차 | Σ_ijgk n_ijgkt | DC, 지역, 차종, 운송군 |
| 운행거리 | Σ_ijgk 2·d_ij·n_ijgkt | DC, 지역, 차종, 운송군 |

각 집계는 모형 변수의 선형 합이므로 문자열 수식을 해석하거나 사용자 코드를 실행하지 않고 하나의 선형 행으로 추가된다. 다기간에서는 매 기간에 같은 행을 적용하며 y는 기간 간 공유된다. 선택한 범위에 해당하는 변수가 하나도 없으면 0으로 계산되므로 진단에 명시한다.

설정 검증은 잘못된 타입/ID/비정상값을 거부한다. 서로 충돌하는 유효 제약은 infeasible로 반환하고 진단 힌트를 제공한다. 진단은 IIS 증명이 아니며 추정 원인을 그렇게 표시한다.

## 해석과 검증

구간 간 결합 제약이 없는 경우 위 모형은 구간별 정확 동적계획으로 q/u/n을 사전 계산한 뒤 y/a MILP로 동치 축약한다. 용량·충족률·예산·회차 제약 또는 사용자 정의 제약이 활성화되면 전체 모형을 사용한다. 사용자 정의 제약은 임의의 구간을 함께 묶을 수 있어 구간 독립성을 보장할 수 없으므로 항상 축약을 해제한다. [methodology.md](methodology.md)에 축약 조건과 근거를 설명한다.

용량은 운송군별 총부피 기준이다. 상품 부피는 0.2 CBM의 배수이며 차량용량 입력을 1 이상 정수 CBM으로 제한한다. 각 차량에 대형상품을 먼저 정수 배치한 후 0.2 CBM 소형상품을 남은 공간에 배치할 수 있으므로 총부피 제약으로 이 사례의 개별상품 적재 가능성을 유지한다. 현실의 3차원 패킹/파손/중량은 별도 문제다.

Σq+u=D, 개설연계, 배정유일성, 운송군 분리, 회차 정수성, 상품부피/차량용량, 서비스거리, DC 용량, 각 활성 템플릿 및 비용 재합계를 Solver와 독립적으로 재검산한다. 사용자 정의 제약은 같은 집계 정의로 결과 문서에서 좌변을 다시 계산하여 검증한다. 양의 gap 또는 시간제한 해를 확정적 전역최적해라고 부르지 않는다. 고정된 후보와 명시된 모델에 대해서만 최적성 상태가 성립한다.
