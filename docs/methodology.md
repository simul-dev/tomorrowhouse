## 9개 기준 비교

다음 평가는 문헌과 본 사례의 66지역·초기 10후보·3차종·최대 3기간 구조에 대한 **설계 판단**이다. 실측 벤치마크나 일반적인 우열 순위가 아니다. 시뮬레이션 최적화는 외부 탐색과 시뮬레이션 평가를 결합하는 방법을 의미한다.

| 기준 | MILP + branch-and-cut | 단순 휴리스틱 | 메타휴리스틱(GA/SA/Tabu 등) | 시뮬레이션 최적화 |
|---|---|---|---|---|
| 문제 적합성 | 개설·배정·정수 회차·선형 비용/제약에 직접 대응 | 초기 후보·빠른 비교에 적합 | 큰 후보공간·비선형 확장에 유연 | 혼잡·불확실한 시간과 운영 평가에 적합 |
| 해 품질 | 실행가능해와 하한/gap을 함께 보고 가능 | 탐욕 선택에 따라 품질 달라짐; 증명 없음 | 좋은 해 탐색 가능하나 일반적인 최적성 증명 없음 | 표본오차와 탐색오차를 함께 관리해야 함 |
| 계산시간 | 난해한 정수 문제에서는 증가; 제한시간 적용 | 통상 빠른 구성 가능 | 반복 횟수와 평가 비용에 좌우 | 반복 모사 비용과 반복실험 필요 |
| 설명 가능성 | 변수·목적·제약별 연결 명확 | 선택 규칙은 간단 | 연산자·벌점·종료 조건 설명 필요 | 운영 과정은 설명 가능하나 선택 원인 분리 어려움 |
| 사용자 DC 위치 변경 | 거리계수·허용 연결 갱신 후 재해결 | 쉽게 재계산 | 후보와 비용 평가를 갱신 | 네트워크 및 모사 입력 재구성 |
| 동적 제약 추가 | 지원 템플릿을 선형 행/상한으로 변환 | 규칙마다 수선 로직 추가 | 실행가능성 보장·수선 로직 필요 | 제약 확인과 위반 처리 별도 필요 |
| 향후 확장성 | 다기간·예산·거리·다상품에 자연스러움; 대규모는 분해 검토 | 복잡한 상호작용에서 관리 부담 | 비선형 평가와 결합 가능 | 시간창·대기열·고장·재고에 강점 |
| 오픈소스 사용 | SciPy/HiGHS로 가능 | 직접 구현 가능 | 공개 라이브러리 또는 직접 구현 가능 | 공개 모사 엔진 가능, 통합 작업 필요 |
| 웹 통합 | 구조화된 입력/결과와 작업 API로 분리 | 응답 빠르고 단순 | 장시간 작업 관리·재현 seed 필요 | 장시간 반복 작업·신뢰구간 출력 필요 |

현재 데이터는 일별 정상상태 수요와 비용·용량이 중심이다. 따라서 해석 가능한 제약과 최적성 gap을 제공하는 MILP를 핵심으로 채택한다. 휴리스틱은 후보 생성에 한정한다. 확률분포·운행시간·작업시간 자료가 없는 상태에서 시뮬레이션을 추가해 정밀도가 높아진 것처럼 표현하지 않는다. 공식 제품 자료도 정적 네트워크 최적화와 시간 기반 모사를 구분한다. [anyLogistix 공식 튜토리얼](https://anylogistix.help/tutorial/tutorials.html)

## 초기 후보 10개를 만드는 알고리즘

허용점은 Excel의 경기 31개 지역 좌표, 서비스 대상은 전체 66개 지역이다. 서울·인천 수요는 목적 평가에 포함하지만 최초 후보로 선택하지 않는다. 지역 가중치는 일별 물동량 `w_i = large_i + 0.2 × (small_i + premium_i)` CBM이다. 인구를 다시 곱하면 이미 주어진 수요와 이중 가중되므로 사용하지 않는다.

1. 전체 가중 거리합 `Σ_i w_i d(i,j)`가 가장 작은 경기 점 하나를 선택한다.
2. 현재 후보집합 C에 각 미선택 경기 점 j를 추가했을 때 `Σ_i w_i min_{k∈C∪{j}} d(i,k)`가 가장 작은 점을 추가한다.
3. 10개가 될 때까지 반복한다. 동일한 값이면 일정한 지역 ID 순서로 결정하여 재현성을 확보한다.
4. 지도에서 후보를 추가·삭제·이동하면 수정된 후보집합을 독립 시나리오 입력으로 보존한다.

이는 가중 거리 목적을 이용한 greedy location 휴리스틱이다. 개설비·차량의 계단형 비용·프리미엄 서비스거리까지 최적화한 10개라고 주장하지 않는다. 후보를 정하는 단계와 그중 실제 DC를 개설하는 단계는 서로 다른 결정이다. 동일 후보가 입력되면 같은 모델이 구성되며, 각 실행 결과에 입력과 파라미터를 연결한다.

## 통합 최적화에서 지켜야 할 구조

- `y_j`는 개설 여부이며 3년 통합모형에서 기간과 무관하게 공유한다. 연도별 수요·배정·흐름·회차는 각각 결정한다. 단일연도별 최적해를 단순 합산한 값은 3년 공통 개설의 최적값이 아니다.
- 한 지역·한 기간에는 최대 하나의 DC만 배정한다. 출고는 배정과 개설에 연결한다. 전체 미충족을 허용하면 무배정도 가능하다. 상품별 다른 DC로 분할하지 않는다.
- 상품흐름과 미충족은 개수 단위 정수다. 대형·소형은 일반 운송군, 프리미엄 소형은 별도 운송군으로 각 차종 회차와 용량을 가진다. 가상 혼재 시나리오만 이 분리를 완화한다.
- 직배송 회차는 `DC → 단일 지역 → DC`다. 고객 방문 순서·차량별 상세 시간표 변수는 없다. 차종별 일일 운행 상한은 차량 대수와 다르다.
- 거리 밖의 프리미엄 출고를 금지하되 해당 지역의 일반 수요 출고까지 자동 금지하지 않는다. 혼재 시나리오에서도 프리미엄 출고의 거리 제한을 유지한다.
- 상품량에 비례한 단순 운송비 대신 `(차종 고정비 + 편도거리 × 차종 km 단가) × 정수 회차`를 사용한다. 총 운행거리 KPI는 왕복거리이다.
- 미충족 허용·패널티는 서비스 실패를 수치화한다. 전량 충족 정책에서는 미충족 상한을 0으로 설정한다. 큰 벌점만으로 전량 충족이 항상 강제된다고 간주하지 않는다.

세부 수식은 [mathematical-model.md](mathematical-model.md)에 정의한다. 위 구조는 사례와 연구자 가정을 반영한 모델링 결정이다. 직배송·혼재·시설 결정의 통합 필요성은 관련 연구를 참고했다. [Azizi & Hu (2020)](https://doi.org/10.1016/j.ijpe.2020.107648), [Potoczki 외 (2024)](https://doi.org/10.1016/j.ijpe.2024.109349)

## 독립 구간의 정확한 동적계획 축약

초기 전체 MILP의 원본 15초 시험에서는 gap 6.37%가 남았다. 이 데이터의 구조를 이용하여 `backend/patterns.py`에 정확한 전처리를 추가했다. 이는 후보 생성 휴리스틱과 다르며, 아래 조건에서 원래 MILP와 같은 최적 목적값을 보존한다.

DC 용량, 회차 상한, 충족률 하한, 예산 제약이 없으면 특정 DC–지역–기간의 운송군별 물량·차량 결정은 다른 구간과 독립이다. 출고 상품 한 개의 순편익은 `패널티−처리비−공급비`로 상품에 공통이므로, 고정 적재공간에서 0.2 CBM 상품을 먼저 배치하면 충족 개수를 최대화한다. 양의 차량비용 아래 총용량을 `ceil(수요 CBM)+최대차량 CBM−1`까지만 열거해도 충분하다. 정수 CBM별 최소 배차비를 unbounded knapsack DP로 계산하고 미충족 비용을 더해 구간의 최적 출고·회차 계획을 얻는다.

해당 계획의 비용을 배정 이진변수 계수로 사용하면 공유 개설 y와 기간별 배정 a만 남는 축약 MILP가 된다. 모든미충족 상수비용도 목적식에 남겨 상대 gap의 분모를 보존한다. 결과는 원래 q/u/n 변수로 복원하고 같은 독립 검산을 수행한다. 자원을 공유하는 제약이 활성화되면 항상 원래 전체 MILP를 사용한다. DP 상태공간이 과도한 사용자 데이터도 전체 MILP로 전환한다. 작은 무작위 사례에서 전체 MILP와 동치 여부를 확인한다.

## 실행·검증 정책과 확장

모델은 거리·금지 연결을 먼저 계산하고 희소 선형 제약으로 구성한다. 상품 수요와 차량용량에서 유한 상한을 계산하여 임의의 거대 상수 사용을 피한다. 좌표·수요·차량·제약 변경 시 계수와 상한을 다시 구성한다. 비활성 제약은 모델에 넣지 않고, 적용된 제약의 이름·설정값을 결과와 연결한다. 수요별 상한 강화의 일반적 근거는 저자 교재에서 확인했다. [Facility location formulations](https://scipbook.readthedocs.io/en/latest/flp.html)

`optimal`은 주어진 후보·거리모형·수치 허용오차 하에서의 Solver 판정이다. 시간 제한이면 검증을 통과한 incumbent가 있을 때만 실행가능한 제한시간 해를 제공한다. incumbent가 없으면 결과표를 성공처럼 표시하지 않는다. `infeasible`은 실행불가능, `unbounded`와 기타 오류는 설정·모형 문제를 조사할 상태로 구분한다. 시간과 gap은 실제 반환값으로 표시한다. [SciPy 상태·옵션·MIP gap](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html)

추가 검증은 상품별 보존, 개설·배정 연결, 단일 DC, 운송군·차량 적재, DC 용량, 거리, 회차 상한, 비용 합계와 예산·충족률을 독립 계산한다. 작은 사례는 전수열거 또는 손계산 최적값과 비교하고, 원본 사례는 실행시간·gap·검증 결과를 기록한다.

규모가 커지면 후보 입지와 기간별 운영을 분리하는 분해법을 검토한다. 단, 본 모형의 운영 변수에도 정수성이 있으므로 연속 LP 하위문제를 전제로 한 고전 Benders 절차를 그대로 적용할 수 있다고 가정하지 않는다. Logic-based/integer Benders, Lagrangian 완화, 제한된 MIP 등을 별도 검증해야 한다. 2024 다기간 연구와 2026 확률적 연구는 확장 경로의 참고이며 본 구현이 그 알고리즘을 구현한 것은 아니다. [Štádlerová 외 (2024)](https://doi.org/10.1016/j.cor.2023.106395), [Wu 외 (2026)](https://doi.org/10.1016/j.cor.2025.107316)

도로거리·교통시간과 도서 접근성, 임대가능 부지, 실제 차량 근무시간, 수요 불확실성은 후속 데이터 확보 후 확장한다. 후보 좌표의 자동 연속 최적화나 토지 적합성 검증은 현재 모델의 보장 범위에 포함되지 않는다.
